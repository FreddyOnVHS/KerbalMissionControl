KMC 14.22.16 — Fixed KSP State-Vector Encounter Sampling

Purpose
-------
Replace 14.22.15's packet-wide fitted frame calibration with KSP's own
right-handed inertial state-vector path, matching the approach used by
established KSP tooling.

Implementation
--------------
For every projected patch point:
1. KSP solves true anomaly at the requested UT:
   orbit.TrueAnomalyAtT(orbit.getObtAtUT(ut))
2. KSP generates the state at that anomaly with future rotation disabled:
   GetOrbitalStateVectorsAtTrueAnomaly(..., ut, false, ...)
3. The position is converted through:
   Planetarium.Zup.WorldToLocal(position)
4. Child-body encounter patches add the child body's position generated by
   the exact same method at the exact same UT.

This removes:
- fitted KSP->KMC frame calibration
- dependence on the active vessel orbital plane
- inferred future anomaly
- encounter-specific branch/sign guesses

Build
-----
Rebuild KMC.Plugin in Release.
Redeploy KMC.Plugin.dll to GameData/KMC/Plugins.
