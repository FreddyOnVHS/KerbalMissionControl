# KMC 14.22.1 — 3D Orbit Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an efficient Mission Control MAP page that renders KSP-authoritative active-vessel, target, maneuver-node, patched-conic, and encounter data in a true rotatable 3D orbital display.

**Architecture:** KSP publishes a dedicated bounded orbital-map snapshot over a new side-channel protocol. Mission Control receives and validates snapshots, converts conic elements into cached 3D geometry only when trajectory-defining data changes, and lets the existing cached `MissionDisplay` render camera-transformed geometry plus compact engineering panels. Camera interaction is local to Mission Control and must never trigger KSP work or orbital-geometry regeneration.

**Tech Stack:** C# / .NET Framework 4.8, KSP 1.x API (`Assembly-CSharp`), WinForms / System.Drawing, UDP loopback side channels, pytest structural/regression harness under `Tools`.

**Spec:** `docs/superpowers/specs/2026-09-15-kmc-14-22-1-3d-orbit-map-design.md`

## Global Constraints

- Base implementation on frozen KMC 14.21.10 at `34ecdfdcfb44aef63b3444ee98b47ead5c8f3568` plus the approved design-doc commit on `design/14.22.1-3d-orbit-map`.
- Use a dedicated versioned orbital-map protocol; do not modify the frozen general flight-telemetry packet.
- Initial orbital-map telemetry cadence is approximately **5 Hz**.
- Use a **body-centered inertial frame** with the current reference body at `(0,0,0)`.
- Preserve true relative orbital geometry; do not apply non-uniform spatial distortion.
- The renderer is a data display, not photorealistic: no terrain, atmosphere effects, clouds, starfield, or required textures.
- Geometry rebuilds occur only when trajectory-defining state changes; timestamp-only updates and camera movement must not rebuild conics.
- The MAP page must stop/throttle expensive redraw work while another Mission Control page is active.
- Invalid packets must be rejected without destroying the last valid snapshot.
- LIVE / STALE / UNAVAILABLE presentation is mandatory.
- 14.22.1 displays KSP-authoritative solutions only; KMC-generated transfer calculations and maneuver creation remain out of scope.
- **KSP Plugin DLL Required? YES**

## File Structure

Create small, single-purpose units rather than placing the entire feature into `MainForm.cs` or `MapPage.cs`.

- `KMC.shared/OrbitMapPacket.cs` — transport DTOs, bounded serialization/parsing, protocol constants.
- `KMC.Plugin/OrbitMapTelemetrySender.cs` — KSP-only extraction of active orbit, target, nodes, and future patches; 5 Hz sender.
- `KMC.MissionControl/Telemetry/OrbitMapTelemetryReceiver.cs` — UDP receiver and freshness timestamps.
- `KMC.MissionControl/Telemetry/OrbitMapSnapshotStore.cs` — thread-safe last-good snapshot + receive counters.
- `KMC.MissionControl/Rendering/OrbitMap/OrbitMapVector3.cs` — lightweight immutable vector math independent of Unity.
- `KMC.MissionControl/Rendering/OrbitMap/OrbitMapConicSampler.cs` — orbital-elements-to-3D cached points.
- `KMC.MissionControl/Rendering/OrbitMap/OrbitMapSceneCache.cs` — trajectory fingerprinting, immutable render snapshot, rebuild counters.
- `KMC.MissionControl/Rendering/OrbitMap/OrbitMapCamera.cs` — yaw/pitch/zoom and projection.
- `KMC.MissionControl/Rendering/OrbitMap/OrbitMapRenderer.cs` — body/orbits/markers/labels/panels only; no propagation.
- `KMC.MissionControl/Pages/MapPage.cs` — page composition, freshness state, camera/control hit targets.
- `KMC.MissionControl/Pages/IMissionPagePointerInput.cs` — narrow pointer-input contract for interactive mission pages.
- Modify `MissionDisplay.cs` only to route mouse input to pages implementing that interface and request cached-canvas rebuilds.
- Modify `MainForm.cs` to start/stop receiver, register real MAP page, and keep existing display refresh behavior.
- Modify both project files to compile the new sources and linked shared packet.
- Add `Tools/OrbitMap/tests/` pytest coverage for protocol shape, project wiring, renderer boundaries, caching rules, and MAP registration.

- [ ] **Step 3: Implement orbital-element conversion**

Use standard perifocal coordinates:

```text
p = a * (1 - e^2)
r = p / (1 + e*cos(nu))
perifocal = (r*cos(nu), r*sin(nu), 0)
```

Rotate by argument of periapsis, inclination, and LAN into the KMC body-centered inertial frame. Keep all calculations in `double`; convert to screen floats only in projection.
